# Metronome

A metronome for OVOS - set a tempo in BPM and get an audible click track, adjustable time signature. Deterministic timing, no audio samples required (a generated click tone). Useful for musicians practicing offline.

> **This is a skeleton only - not implemented yet.** Repo, structure,
> and design notes are in place; the actual skill logic hasn't been
> written. See "Design notes" in [DEVELOPMENT.md](DEVELOPMENT.md).

## Why this exists

Nothing like this exists in the OVOS ecosystem yet (checked before starting). Purely deterministic - a fixed-interval click, no cloud dependency, no API key.

## Planned usage (not yet functional)
```
"set a metronome to 120 bpm"
"start a metronome"
"stop the metronome"
```
